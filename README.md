# Vocab-Trainer_Franche_for_Germans
This a program to self control the known vocabulary.
It supports German to Franche and reversed and all regular terms of verbs.
The existing files are just examples and no complete lists.

Dieses Programm kann dazu verwendet werden, die eigenen Vokabelkenntnisse zu prüfen.
Es unterstützt Deutsch-Französisch und umgekehrt, sowie alle gebräulichen Zeitformen. Beim Passé Composé muss man immer von der maskulinen Version ausgehen.
Die angehängten Dateien sind Beispiele und keine vollständige Liste. Sie können zu Testzwecken verwendet werden.

The pictures are from Pixabay or self-made.
Die Bilder stammen von Pixabay oder wurden selbst erstellt.
